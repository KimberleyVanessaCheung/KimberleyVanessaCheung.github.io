# Kimberley Vanessa Cheung - Portfolio Website

A futuristic portfolio website showcasing creative development projects, professional experience, and interactive work at the intersection of biotech, robotics, and human performance technology.

## Features

- **Futuristic Design**: High-tech aesthetic with animated particles, gradient effects, and smooth transitions
- **Responsive Layout**: Fully responsive design that works on all devices
- **Interactive Animations**: Particle system that responds to mouse movement
- **Experience Section**: Highlights ex Hanson Robotics and biotech educator/software engineer roles
- **Project Showcase**: Featured projects with live demos and code links
- **Smooth Navigation**: Seamless scrolling and page transitions

## Project Structure

```
├── .vscode/                          # VS Code editor settings and tasks

```

## Open in VS Code / Cursor

1. Open the workspace file:
   - **File → Open Workspace from File…**
   - Select `Website Portfolio.code-workspace`
2. Install recommended extensions when prompted (Live Server, HTML CSS Support, Prettier).
3. Preview the site using either option:
   - **Live Server**: Right-click `index.html` → **Open with Live Server**
   - **Built-in task**: **Terminal → Run Task → Start Local Server**, then visit `http://localhost:8080/index.html`
